# Python Pandas & Matplotlib Practice and Assessment

A hands-on Python repository containing Pandas exercises, Matplotlib visualizations, Jupyter Notebook assessments, and CSV datasets for learning data analysis and visualization.

## 📌 About the Project

This repository helps beginners learn and practice **Pandas** for data manipulation and **Matplotlib** for data visualization. It includes practical examples of Series, DataFrames, filtering, sorting, grouping, aggregation, and charts using real-world-style datasets.

## 🎯 Topics Covered

### 🐼 Pandas
- Series and DataFrame creation
- Data selection using `loc[]` and `iloc[]`
- Conditional filtering with multiple conditions
- Handling missing values using `dropna()` and `fillna()`
- Column operations and renaming
- Counting values using `value_counts()`
- Grouping and aggregation using `groupby()`, `sum()`, and `mean()`
- Sorting data using `sort_values()`

### 📊 Matplotlib
- Bar charts for category-wise quantity and country-wise sales
- Line graphs for daily sales trends
- Category-wise average price visualization
- Pie charts for order distribution by category
- Country-wise share of total sales
- Adding chart titles, axis labels, markers, colors, and grid lines
- Displaying values using `plt.bar_label()`
- Formatting dates and labels using `plt.xticks()`
- Improving chart layout using `plt.tight_layout()`

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/samil2004/pandas.git
```

### 2. Navigate to the project folder

```bash
cd pandas
```

### 3. Install the required libraries

```bash
python -m pip install pandas matplotlib jupyter
```

### 4. Launch Jupyter Notebook

```bash
jupyter notebook
```

Alternatively, open the project folder in Visual Studio Code and run the notebooks using the Jupyter extension.
