# Python Pandas Practice & Assessment

A hands-on Python Pandas repository containing practice exercises, Jupyter Notebook assessments, and CSV datasets for learning data manipulation and analysis.

## 📌 About the Project

This repository helps beginners learn and practice **Pandas**, a Python library used for data analysis and data manipulation. It includes practical examples of Series, DataFrames, filtering, sorting, grouping, and handling missing values.

## 🎯 Topics Covered

- **Series:** Creating and filtering Pandas Series.
- **DataFrames:** Creating DataFrames from lists and dictionaries.
- **Data Selection:** Selecting rows and columns using `loc[]` and `iloc[]`.
- **Conditional Filtering:** Filtering records using comparison operators and multiple conditions.
- **Data Cleaning:** Handling missing values using `dropna()` and `fillna()`.
- **Column Operations:** Renaming columns and selecting specific columns.
- **Value Counting:** Counting occurrences using `value_counts()`.
- **Grouping and Aggregation:** Using `groupby()`, `sum()`, and `mean()`.
- **Sorting:** Sorting records using `sort_values()`.
